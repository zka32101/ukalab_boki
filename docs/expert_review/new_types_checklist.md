- 本一覧は人が確認するための優先順位表。判定・コメント列は確認者が埋める。問題文は引用せず、id と短い要約のみ載せる。問題の全文と解説はデータ側で見る。

## 1. 目的と注意

- 新形式 36 問は現在、`lib/exam_data/feature_flags.dart` の `kNewQuestionTypesEnabled = false` により出題されない（休眠中）。
- 専門家確認が済むまで `kNewQuestionTypesEnabled` を `true` にしない運用を推奨する。本一覧の作成ではコードのフラグは変更していない。
- 一覧にある「確認の観点」は確認の手がかりであり、正解や正しい勘定科目・金額を示すものではない。正誤の判断は確認者が行う。

## 2. 重要な注意（模擬試験は新形式に未対応）

フラグを `true` にした場合、模擬試験は新形式を扱えない。実コードの現状は次のとおり。

- `lib/mock_exam/mock_exam_page.dart:248-251`: `trueFalse` / `cloze` / `reverseLookup` の判定は常に `false` を返す（「新タイプ未対応」とコメントあり）。
- `lib/mock_exam/mock_exam_page.dart:483-486`: 同 3 形式は `SizedBox.shrink()` を返し、解答欄が表示されない。
- `lib/mock_exam/mock_exam_review_page.dart:93-96`: 振り返り画面でも同 3 形式は何も表示しない。

したがって、模擬試験の出題元に新形式が含まれる状態でフラグを `true` にすると、解答欄が出ず常に不正解になる。内容の確認とは別に、フラグを `true` にする前に模擬試験側の対応が必要。

## 4. 範囲の確認

全 36 問の `sourceRef` は、商工会議所の出題区分表（2026-07-31 最終改定 / 2027-04-01 施行）を基準にしている。確認時に最新の区分で、各問の `sourceRef` が示す項目が3級の範囲か、項目番号が合っているかを確認する。

## 5. 確認後の手順

1. 判定が OK の問題: `ai-draft` タグを外す PR を別に作る。
2. 修正・削除の判定が出た問題: 内容を直す（または削除する）PR を別に作る。
3. データを変更した PR では contentVer を更新する。
4. `kNewQuestionTypesEnabled` の扱い（模擬試験側の対応を含む）は別途決定する。
5. 記録は確認日（年月）と確認者区分のみ。氏名等は記録しない。
